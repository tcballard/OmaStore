# ADR 0012: authored software shelf

Accepted by Tom, 10 September 2026. Supersedes ADR 0011's visual direction.
The approved square-edged concept uses graphite, warm white and amber,
Instrument Serif display typography, IBM Plex Sans body text, and zero-radius
store surfaces. This is an intentionally dark storefront, including on a light
desktop; portal text scaling still applies. The upstream calculator screenshot
retains the application's original appearance.

The functional signature is a persistent, horizontally browsable app shelf.
App selection changes the detail surface without rebuilding the shelf or
resetting its position. At smaller widths the hero stacks and scrolls, while
the shelf stays accessible. Full filters remain on Browse. Secondary native
workspaces remain reachable through More. Additional app information is an
explicit disclosure; installation review and its independent confirmation gate
are unchanged. No payment or execution capability is enabled by this change.

Bundled typefaces and Feather category icons are licensed assets. Category
icons are store navigation aids, not fabricated publisher logos. No generated
mockup is shipped as UI or used as compatibility evidence. The exact approved
visual is the square-edged concept displayed immediately before Tom's build
authorisation. Actual window captures and native keyboard checks form the
implementation receipt; real Omarchy acceptance remains distinct.
