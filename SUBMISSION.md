# Application submissions

Application intake is not open yet. This file establishes the intended policy; it is not an approval service.

Future submissions identify the maker, project-control evidence, exact release/source or artifact, distribution route, software licence, price model, runtime requirements, real media and support destination. Open-source and proprietary applications follow different documented inspection paths.

Structural validation checks the record. Independent reviewers then record compatibility results against actual release bytes and an actual Omarchy environment. Approval binds to the complete reviewed candidate. A later edit or changed release cannot inherit that approval automatically.

Authors can revise findings, request publication, appeal decisions and retain their own distribution and checkout. Listing and normal review are free. External sales and support links have no OmaStore fee; third-party provider fees may still apply. Payment does not influence approval, ranking or editorial selection.

Do not submit applications, binaries or personal information through an improvised workflow while intake is being built. B04–B09 define identity, drafts, checks, review and publication.
